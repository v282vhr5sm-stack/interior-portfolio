■ 인테리어 포트폴리오 사용법

[관리 페이지]  .../admin.html   ← 나만 쓰는 곳 (포트폴리오 관리 비밀번호로 로그인)
[고객용 링크]  .../             ← 고객에게 보내는 주소 (현장별 공사후 사진만, 보기 전용, 저장·캡처 방지 + 워터마크)

■ 사진 올리기 (노트북 · 아이폰 · 아이패드 어디서나, 올리면 다른 기기에 바로 반영)
1) 관리 페이지 > "＋ 올리기"
2) 현장 고르기 (새 현장 만들기 / 기타 작업물 = 현장명 없음·캡쳐)
3) 단계 (공사전 / 공사중 / 공사후)
4) 공간 (거실, 현관, 주방, 메인룸, 작은방 … 또는 직접 입력)
5) "사진 선택" → 여러 장 한 번에 고르면 자동으로 올라감
   → 공간을 바꿔서 또 고르면 됨

■ 화면 캡쳐해서 올리기 (현장/단계/공간 먼저 고르기)
- 노트북: "✂ 화면 캡쳐해서 올리기" → 캡쳐할 창/탭 선택 → 올릴 부분 드래그 → "선택한 부분 올리기"
          또는 Win+Shift+S 로 캡쳐 → 관리 페이지 올리기 화면에서 Ctrl+V
- 아이폰/아이패드 (사진첩에 안 남기기): 스크린샷 → 왼쪽 아래 미리보기 → 완료 → "복사 후 삭제"
          → 올리기 화면의 "캡쳐 붙여넣기" 칸을 길게 눌러 "붙여넣기" → 부분 드래그 → 올리기
- 이미 있는 사진도 "고른 사진을 잘라서 올리기" 체크하면 잘라서 올릴 수 있음

■ 노트북에서 폴더 통째로 올리기
관리 페이지 > 올리기 > "폴더 고르기" 로 이 폴더 안 "사진" 폴더를 고르면
아래 규칙대로 현장/단계/공간을 알아서 나눠서 올림 (이미 올린 사진은 건너뜀)

사진\
 ├ 현장\
 │  ├ 송파 헬리오시티 34평\
 │  │  ├ 공사전\ 거실\ 주방\ ...
 │  │  ├ 공사중\ 거실\ ...
 │  │  ├ 공사후\ 거실\ 현관\ 주방\ 메인룸\ 작은방\ ...
 │  │  └ 정보.txt          ← (선택) 위치/평수/연도/설명
 │  └ 분당 아파트\          ← 공사전·중 없으면 공간 폴더만 (=공사후)
 └ 기타작업\                ← 현장명 없음 / 캡쳐
    ├ 거실\ 주방\ ...

■ 수정하기
- 사진 오른쪽 위 작은 × → 그 사진 바로 삭제
- 사진 누르기 → 아래에서 공간·단계·현장 바꾸기, 대표사진 지정, 삭제
- 현장 페이지 → 정보 수정 / 고객에게 숨기기 / 맨 앞으로 / 현장 삭제

■ 저장공간
- 사진 파일: Cloudflare R2 (10GB 무료, 고객이 보는 전송량 무료) — 관리 페이지 > 올리기 아래에 사용량 표시
- 현장·공간 정보: Cloudflare D1 데이터베이스 (5GB 무료)
- 서버: Cloudflare Worker (worker 폴더) — 다른 기기에서 바꾼 내용은 10초 안에 자동 반영
- 1장당 약 0.3~0.6MB (원본이 커도 올릴 때 자동으로 줄임) → 약 1만 5천~3만 장
- 10GB에 가까워지면 경고, 꽉 차면 업로드를 막음 (요금 안 나가게)

■ 사이트 이름·연락처·워터마크 글자
config.js 를 메모장으로 열어서 name, tagline, contact, watermark 수정 후 다시 올리기
